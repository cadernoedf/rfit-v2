# Mapa de arquivos

- `apps/student/`: portal do aluno (HTML, JS e CSS separados).
- `apps/professor/`: portal do professor (HTML, JS e CSS separados).
- `services/api/src/index.js`: entrada do Worker.
- `services/api/src/routes/`: rotas HTTP.
- `services/api/src/middleware/`: futuro middleware de autenticação e autorização.
- `services/api/src/services/`: regras de negócio.
- `services/api/src/utils/`: utilitários.
- `database/migrations/`: migrações D1.
- `tests/`: testes.
